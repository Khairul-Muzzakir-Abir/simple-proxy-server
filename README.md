# Simple Proxy Server
A basic proxy server implemented in Python using sockets and threading. This project is intended for educational purposes and to demonstrate network programming skills.

## Features

- Forwards HTTP requests from a client to a remote server.
- Supports basic authentication.
- Logs requests and responses for troubleshooting.
